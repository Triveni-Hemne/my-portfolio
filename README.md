## ✨ Features

- ⚡ Fast performance with Vite build tool
- 📱 Fully responsive — works on mobile, tablet, and desktop
- 🎨 Clean UI with Tailwind CSS utility classes
- 🧩 Reusable Vue 3 components
- 🗂️ Projects showcase with tech stack details
- 📬 Contact section with LinkedIn, GitHub, and email links

## 🛠 Tech Stack

| Technology | Purpose |
|-----------|---------|
| Vue 3 | Frontend framework (Composition API) |
| Vite | Build tool & dev server |
| Tailwind CSS | Utility-first styling |
| GitHub Pages | Deployment & hosting |

---

## 🚀 Getting Started

```bash
# Clone the repo
git clone https://github.com/Triveni-Hemne/my-portfolio.git

# Navigate into the project
cd my-portfolio

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
